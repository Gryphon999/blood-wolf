# Blood Wolf — дизайн-документ (v1)

**Дата:** 2026-09-11
**Платформа:** Яндекс.Игры (WebGL)
**Движок:** Phaser 3 (чистый JavaScript, ES-модули)
**Жанр:** мрачная dark-fantasy карточная дуэль (Гвинт-подобная) с сюжетом и асинхронным онлайном.

---

## 1. Концепция и рамки

Карточная игра в мрачном dark-fantasy сеттинге, вдохновлённом «Ведьмаком», но **без использования его IP** (свой мир, свои имена, свой арт). Игрок собирает колоду, проходит сюжет против ИИ-колод и боссов, сражается онлайн с колодами других игроков, зарабатывает золото, покупает и улучшает карты, растёт в рейтинге.

### Ключевые решения (зафиксированы на брейншторме)

| Вопрос | Решение |
|---|---|
| Движок | Phaser 3, чистый JS, ES-модули |
| Платформа | Яндекс.Игры, WebGL, без своего сервера |
| Модель боя | Гвинт (полный ruleset — цель; собирается слоями) |
| Онлайн | Асинхронный PvP («призрачные» колоды реальных игроков + ИИ) |
| Арт | ИИ-генерация; на старте — заглушки (placeholder) |
| IP | Оригинальный мир, без брендов «Ведьмака» |
| Рейтинг | Про мастерство: вес побед доминирует |
| Реклама | Сундук (rewarded, по клику) + interstitial между боями |

### Что входит в v1 (вертикальный срез)

Цель v1 — доказать, что движок Гвинта работает и игра затягивает. Полный Гвинт остаётся целью, набивается слоями.

| Система | В v1 | Позже |
|---|---|---|
| Движок Гвинта | 3 ряда, раунды best-of-3, ход/пас, подсчёт силы | — |
| Спец-карты | погода, усиление ряда (рог), урон по ряду, лечение, герой (иммунитет) | шпионы, медики-цепочки, редкие эффекты |
| Фракции | 2 («Люди», «Чудовища») | + ещё 2-3 |
| Карт всего | ~40-50 | 150+ |
| Сюжет | 1 локация, 4-5 боёв + 1 босс | новые локации/боссы |
| Онлайн | асинхронный PvP + лидерборд | реал-тайм (.NET/SignalR) отдельным проектом |
| Экономика | золото, покупка, улучшение карт | крафт, редкости, наборы |
| Сундук | реклама → рандом-карта + золото | ежедневные награды |

## 2. Архитектура

Главный принцип: **правила игры отдельно от отрисовки.** Слои соответствуют Clean Architecture.

- `engine/` = **Domain** — чистые правила Гвинта, не зависят от Phaser, покрываются юнит-тестами.
- `services/` = **Infrastructure** — обёртки над внешним Yandex SDK.
- `scenes/` + `ui/` = **Presentation** — Phaser рисует то, что говорит engine.
- `data/` = контент (карты, сюжет) — меняется без правки логики.

Зависимости направлены только внутрь: сцены знают про движок; движок про сцены — нет.

### Структура проекта

```
blood-wolf/
├─ index.html
├─ vite.config.js
├─ src/
│  ├─ main.js                 # старт Phaser, регистрация сцен
│  ├─ engine/                 # ЧИСТЫЙ движок Гвинта — без Phaser
│  │  ├─ GwentMatch.js        # состояние матча: раунды, ходы, пас, победитель
│  │  ├─ Board.js             # 3 ряда × 2 стороны, подсчёт силы
│  │  ├─ Card.js              # модель карты + применение эффекта
│  │  ├─ effects.js           # погода, рог, урон по ряду, лечение, герой…
│  │  └─ ai/OpponentAI.js     # ИИ: какую карту сыграть / когда пасовать
│  ├─ data/
│  │  ├─ cards.js             # определения всех карт
│  │  └─ story.js             # локации, бои, колоды боссов
│  ├─ scenes/                 # ТОЛЬКО Phaser
│  │  ├─ BootScene.js         # загрузка ассетов + инициализация Yandex SDK
│  │  ├─ MenuScene.js         # главное меню
│  │  ├─ BattleScene.js       # экран боя — визуализация GwentMatch
│  │  ├─ DeckScene.js         # сбор колоды + улучшение карт
│  │  ├─ ShopScene.js         # магазин + сундук (реклама)
│  │  └─ LeaderboardScene.js  # рейтинг игроков
│  ├─ services/
│  │  ├─ YandexSDK.js         # обёртка: сохранения, лидерборды, реклама, вход
│  │  ├─ PlayerProfile.js     # золото, коллекция, колода, прогресс
│  │  └─ Matchmaker.js        # достаёт колоду соперника для онлайна
│  └─ ui/                     # переиспользуемые UI-компоненты
└─ assets/                    # арт карт, фоны, шрифты, звуки
```

### Обёртка Yandex SDK

`YandexSDK.js` — единственная точка контакта с платформой. Поддерживает **mock-режим**: при отсутствии SDK (локальная разработка) сохраняет прогресс в `localStorage`. Если Яндекс поменяет API — правится одно место.

### Асинхронный онлайн (`Matchmaker.js`)

1. **Основной путь:** записи лидерборда рядом с рейтингом игрока содержат закодированную строку колоды соперника в `extraData`. Декодируем → бой против неё под управлением `OpponentAI`.
2. **Запасной путь:** если `extraData` в лидерборде недоступен — колода соперника генерируется процедурно под рейтинг игрока. Рейтинг и награды остаются настоящими.

**Фаза 0 (обязательна перед постройкой онлайна):** проверить, что Yandex SDK возвращает `extraData` в записях лидерборда. Если нет — использовать запасной путь.

## 3. Модель данных

### Определение карты (`data/cards.js`) — статика

```js
{
  id: 'toplyak',
  name: 'Топляк',
  faction: 'monsters',      // 'humans' | 'monsters'
  type: 'unit',             // 'unit' | 'special' | 'hero' | 'leader'
  row: 'melee',             // 'melee' | 'ranged' | 'siege' | 'any'
  power: 5,
  effect: null,             // null | 'frost' | 'horn' | 'scorch' | 'heal' | ...
  rarity: 'common',         // common | rare | epic | legendary
  cost: 100,
  art: 'cards/toplyak.png'
}
```

### Профиль игрока (`PlayerProfile`) — облако Яндекса

```js
{
  gold: 250,
  collection: {
    'toplyak': { count: 2, level: 1 },
    'flame_sign': { count: 1, level: 3 }
  },
  deck: ['toplyak', 'toplyak', ...],
  leaderId: 'monster_king',
  faction: 'monsters',
  story: { location: 1, battlesWon: 3, bossDefeated: false },
  stats: { pvpWins: 12, pvpLosses: 5 }
}
```

**Улучшение карты:** поле `level` (1→3). Каждый уровень даёт **+1 к силе** и стоит золота.

### Экономика v1 (числа черновые, балансятся позже)

| Действие | Награда / Цена |
|---|---|
| Победа в сюжетном бою | +50 золота |
| Победа над боссом | +200 золота + редкая карта |
| Победа в онлайне (PvP) | +30 золота + рейтинг |
| Купить карту | common 100 / rare 300 / epic 800 |
| Улучшить карту (ур. 2 / 3) | 150 / 400 |
| Сундук (за рекламу) | рандом-карта (по редкости) + 20–50 золота |

### Рейтинг — «Сила» (Might)

Лидерборд Яндекса хранит одно число. Считаем сводную «Силу», **с доминирующим весом побед (про мастерство)**:

```
Might = pvpWins × 1000  +  сумма силы всех карт коллекции (с улучшениями)  +  сила лидера
```

Высокий множитель побед (×1000) гарантирует, что рейтинг отражает мастерство, а сила карт/лидера служит лишь довеском для игроков с равным числом побед. Детальная разбивка (побед / сила карт / сила лидера) и колода для матчмейкинга кладутся в `extraData` записи и показываются в таблице рейтинга.

## 4. Игровые режимы и экраны

### Сюжет (PvE)

- Карта локации → узлы боёв (4-5 обычных + 1 босс).
- Бой = матч Гвинта против ИИ-колоды (`data/story.js` задаёт колоду и лидера врага).
- Победа → золото, иногда карта; босс → редкая карта.
- Между боями — interstitial-реклама (с учётом минимального интервала SDK).
- Прогресс сохраняется в облако.

### Онлайн (асинхронный PvP)

- `Matchmaker` берёт колоду соперника рядом по «Силе» → матч Гвинта под управлением `OpponentAI`.
- Победа → золото + рост «Силы» в лидерборде.
- Экран рейтинга: имя, победы, сила карт, сила лидера.

### Поток экранов

```
Boot → Menu ─┬─► Сюжет  ──► Battle ──► награда ──► Menu
             ├─► Онлайн ──► Battle ──► награда/рейтинг ──► Menu
             ├─► Колода (собрать/улучшить)
             ├─► Магазин + Сундук (реклама)
             └─► Рейтинг (лидерборд)
```

## 5. Тестирование

- **Юнит-тесты (Vitest):** движок Гвинта (эффекты, раунды, пас, победитель), экономика, формула «Силы» — без браузера.
- **Ручная проверка в браузере:** сцены, клики по картам, реклама (mock-режим).
- **Mock-режим Yandex SDK:** локальная игра без Яндекса (сохранения в `localStorage`).

---

## 6. Соответствие правилам Яндекса

- Нет IP «Ведьмака» — свой мир, имена, арт.
- Реклама только по клику (сундук) + interstitial с минимальным интервалом между боями.
- Монетизация и лидерборды только через Yandex SDK.
- Нет лутбоксов за реальные деньги (сундук — только за рекламу).
- Работает без обязательной регистрации; вход через аккаунт Яндекса.
- Лёгкий WebGL-билд (Phaser + Vite) — быстрая загрузка.
