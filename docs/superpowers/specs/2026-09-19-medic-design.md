# Медик — дизайн карты

**Дата:** 2026-09-19  
**Проект:** Blood Wolf

---

## Механика

Медик — юнит-карта с эффектом лечения. При розыгрыше встаёт в ряд как обычная карта, после чего игрок выбирает одну ослабленную карту на своём поле — она восстанавливается до базовой силы.

**Характеристики карты:**
- `id`: medic
- `name`: Медик
- `type`: unit
- `row`: melee
- `power`: 4
- `effect`: heal
- `rarity`: rare
- `art`: medic

---

## Движок — `healUnit`

```js
export function healUnit(match, playerIndex, row, cardIndex)
```

Восстанавливает `card.power = card.def.power` для карты на доске.

**Бросает ошибку если:**
- карта не существует по индексу
- карта — герой (иммунна)
- карта не ослаблена (power === def.power)

Движок не знает о "режиме выбора" — только лечит по конкретному индексу.

---

## Данные — `starterDecks.js`

Добавить в `PLAYER_DECK`:
```js
card('medic', 'Медик', 'unit', 'melee', 4, 'heal', 'rare', 'medic')
```

`applyCard` в GwentMatch ставит Медика в ряд как обычный юнит (effect `heal` не передаётся в `applyEffect`).

---

## UI — `BattleScene.js`

После розыгрыша карты с `effect === 'heal'`:
1. Сцена устанавливает `this.awaitingHeal = true`
2. Все карты игрока на доске с `power < def.power` подсвечиваются зелёной рамкой
3. Клик по карте → `healUnit(match, 0, row, cardIndex)` → подсветка снимается → ход передаётся
4. Если нет ослабленных карт → heal пропускается автоматически

---

## Тесты

- `healUnit` восстанавливает power до базового значения
- `healUnit` бросает ошибку при попытке лечить героя
- `healUnit` бросает ошибку если карта не ослаблена
- `healUnit` бросает ошибку при неверном индексе
