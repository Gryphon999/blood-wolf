# Blood Wolf — экран боя (Phaser): дизайн-документ

**Дата:** 2026-09-11
**Слой:** третий (после engine-core и effects). Первый визуальный слой.

## Цель

Тонкая сцена Phaser, которая визуализирует один матч «Игрок (сторона 0) против ИИ (сторона 1)» на готовом, протестированном движке Гвинта, и переводит клики игрока в вызовы `playCard`/`pass`. Меню, сюжет, онлайн, экономика — вне этого слоя.

## Рамки

- Один матч Игрок vs ИИ (`OpponentAI`). Игрок = сторона 0.
- Карты рисуются заглушками (прямоугольник с именем и силой); ИИ-арт — позже.
- Минимальные стартовые колоды в `data/starterDecks.js` (несколько юнитов + пара спец-карт, имена-заглушки) — только чтобы было чем играть. Полный каталог карт — отдельный слой.
- Ориентация 16:9 (как принято на Яндекс.Играх).

## Раскладка (16:9)

Сверху вниз: рука соперника (рубашкой, число карт) + счётчик выигранных раундов соперника; 3 ряда соперника (осадный/дальний/ближний) с суммой силы; центральная полоса (зона погоды + общий счёт ИИ и игрока); 3 ряда игрока (ближний/дальний/осадный) с суммой силы; рука игрока + кнопка «ПАС» + счётчик раундов игрока.

## Поток ввода (клик-выбор)

1. Клик по карте в руке → карта и допустимые ряды подсвечиваются:
   - `unit`/`hero` → свой ряд по `def.row`.
   - `special`: `horn` → свой ряд; `sign_damage` → ряд соперника; погода/`clear` → без цели: карта разыгрывается **сразу по клику** (ряд не выбирается; для розыгрыша движку передаётся любой валидный ряд, например `melee`, — он игнорируется для погоды/ясного неба).
2. Клик по подсвеченному ряду → `playCard(match, cardIndex, row)`; перерисовка.
3. Кнопка «ПАС» → `pass(match)`.
4. Ход ИИ: после хода игрока, если очередь ИИ (`match.current === 1`) и матч не окончен — сцена берёт `chooseMove(match, 1)`, применяет с небольшой задержкой (индикатор «ИИ думает…»), перерисовывает; повторяет, пока снова не очередь игрока или матч не окончен.
5. Конец раунда → короткое уведомление; конец матча → экран «Победа/Поражение/Ничья».

## Архитектура

Сцена тонкая: никакой игровой логики, только вызовы движка + отрисовка. Правила уже покрыты 43 юнит-тестами.

- `src/ui/layout.js` — **чистый** модуль: по индексу ряда/карты и размеру экрана возвращает координаты. Покрывается юнит-тестами.
- `src/ui/CardView.js` — визуальный компонент одной карты-заглушки (имя, сила, тип; подсветка выбранной).
- `src/ui/RowView.js` — ряд + отображение суммы силы.
- `src/scenes/BattleScene.js` — держит объект матча, рисует состояние, ловит клики, дергает движок, гоняет ход ИИ, показывает конец матча.
- `src/data/starterDecks.js` — две тестовые колоды (карт-определения из существующей модели: `{id,name,faction,type,row,power,effect,rarity,cost,art}`; спец-карты с корректным `row`).
- `src/main.js` — инициализация Phaser (Game config 16:9, регистрация `BattleScene`).

Зависимости: сцена/ui → движок (`engine/**`); движок → сцену **не** знает (как и раньше). `engine/**` остаётся чистым (без Phaser/DOM).

## Тестирование

- **Чистый модуль `ui/layout.js`** — юнит-тесты (Vitest): координаты рядов/карт детерминированы.
- **Сцена** — проверяется вживую в браузере через claude-in-chrome: `npm run dev`, скриншоты, клики по картам/рядам/пасу, прохождение раунда, проверка экрана победы. Автотестами Phaser-сцену не покрываем.
- Существующие 43 теста движка остаются зелёными (сцена ничего в движке не меняет).

## Вне рамок (следующие слои)
