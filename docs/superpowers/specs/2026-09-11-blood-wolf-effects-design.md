# Blood Wolf — спец-карты (эффекты): дизайн-документ

**Дата:** 2026-09-11
**Слой:** второй (после engine-core). Добавляет спец-карты к чистому движку Гвинта.

## Цель

Добавить в движок спец-карты и героев так, чтобы сила карт вычислялась через **пересчёт эффективной силы** из активных эффектов (не мутацией на месте). Всё остаётся чистым JS в `src/engine/**`, покрыто юнит-тестами.

## Модель силы (ключевое решение)

Каждый юнит хранит неизменную **базовую силу** (`card.power`, как сейчас). **Эффективная сила** вычисляется на лету при подсчёте ряда:

```
effectivePower(card, row, board, weather):
  если card.def.type === 'hero'  → вернуть базовую силу (иммунитет)
  p = card.power
  если weather содержит row       → p = 1
  если board.horns содержит row   → p = p * 2
  вернуть p
```

Порядок фиксирован: **погода (=1) → рог (×2)**. Так «рог на ряду под погодой» даёт 2 за юнита — как в Гвинте.

Два вида эффектов:
- **Ауры** (погода, рог) — постоянны в рамках раунда, влияют на текущих и будущих юнитов ряда, пересчитываются при подсчёте.
- **Мгновенные** (урон по ряду) — применяются один раз к юнитам, присутствующим в момент розыгрыша (снижают базовую силу).

## Набор эффектов этого слоя

| Тип карты | Эффект | Поведение |
|---|---|---|
| `hero` | иммунитет | ставится на ряд как юнит, но игнорирует все эффекты |
| `special` `weather_frost` | погода | ставит силу НЕ-героев в ряду `melee` (обе стороны) = 1 |
| `special` `weather_fog` | погода | то же для `ranged` |
| `special` `weather_rain` | погода | то же для `siege` |
| `special` `clear` | ясное небо | снимает всю погоду |
| `special` `horn` | рог | ×2 силе НЕ-героев в выбранном ряду **своей** стороны |
| `special` `sign_damage` | урон по ряду | −2 (пол = 1) каждому НЕ-герою в выбранном ряду **соперника**, единожды |

**Отложено в следующий слой (YAGNI):** лечение/медик (нужен «сброс»/кладбище), шпион, карта-лидер, вторая-третья фракции, полный каталог карт.

## Изменения в движке

- `Board.createBoard()` — добавляет `horns: Set` (ряды с рогом на этой стороне).
- `Board` — новая `effectivePower(...)`; `rowPower(board, row, weather?)` и `totalPower(board, weather?)` считают эффективную силу. Параметр `weather` необязателен (по умолчанию пустой) — существующие вызовы и тесты не ломаются.
- `GwentMatch.createMatch` — добавляет `weather: Set` (глобальная, влияет на обе доски).
- `GwentMatch.playCard` — различает тип карты: `unit`/`hero` → на ряд; `special` → применить эффект (не кладётся на ряд, но ход всё равно переходит).
- `resolveRound` — считает `totalPower(board, match.weather)`.
- `startNextRound` — очищает доски (рог сбрасывается) и `match.weather` (погода живёт только в рамках раунда).

Существующие 28 тестов остаются зелёными (все изменения аддитивны, новые параметры имеют значения по умолчанию).

## Тестирование

Чистые юнит-тесты:
- `effectivePower`: герой-иммунитет, погода=1, рог=×2, погода+рог=2.
- Погода снижает сумму ряда с обеих сторон; «ясное небо» снимает; погода сбрасывается в новом раунде.
- Рог удваивает свой ряд, не трогает героев.
- Урон по ряду: −2 (пол 1), только НЕ-герои, только выбранный ряд соперника, единожды.
- Регресс: `playMatch` с колодой, содержащей спец-карты, по-прежнему всегда завершается.

ИИ (`OpponentAI`) в этом слое остаётся жадным/наивным (специалки играет как карты силы 0); умный розыгрыш спец-карт — будущий слой.
