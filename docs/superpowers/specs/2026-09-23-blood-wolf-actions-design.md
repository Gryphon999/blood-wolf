# Blood Wolf — Активные действия карт и раздача по раундам

**Дата:** 2026-09-23
**Проект:** Blood Wolf (Phaser 3, plain JS ESM, Vite, Vitest, Яндекс.Игры)
**Основа:** `2026-09-19-blood-wolf-v2-design.md` (статусы, Order, Charge, Zeal остаются в силе)

---

## 0. Цель

1. **Каждая карта что-то делает** при выходе (Deploy) или через Приказ (Order), и это действие анимируется.
2. Цель для большинства действий **выбирает игрок** (урон врагу, лечение союзника, дубль, щит).
3. В начале раундов 2 и 3 каждый игрок получает **5 случайных карт из пула своей фракции**.
4. Урон, опустивший силу до 0, **убивает карту**.

Предварительный шаг: закоммитить незакоммиченные слои 12–13 (магазин v2, game feel) до начала работы.

## 1. Архитектура: лог событий

Движок меняет состояние мгновенно и пишет каждое наблюдаемое изменение в `match.events`.
Сцена забирает события (`drainEvents(match)` возвращает массив и очищает лог) и проигрывает их анимациями.

Формат события (плоский объект):

```js
{ type: 'damage', sourceUid, targetUid, amount, powerAfter }
```

Типы событий:

| type | Поля | Когда |
|---|---|---|
| `play` | `uid, player, row` | карта вышла на поле |
| `damage` | `sourceUid?, targetUid, amount, powerAfter` | урон прошёл (после брони). `sourceUid = null` для тиков статусов |
| `shieldBreak` | `sourceUid?, targetUid` | щит поглотил удар |
| `heal` | `sourceUid, targetUid, amount, powerAfter` | лечение |
| `boost` | `sourceUid, targetUid, amount, powerAfter` | бафф |
| `shield` | `sourceUid, targetUid` | выдан щит |
| `destroy` | `uid, player, row` | карта умерла |
| `copyToHand` | `sourceUid, targetUid, newUid, player` | копия ушла в руку |
| `poison` / `bleed` | `sourceUid, targetUid` | наложен статус |
| `rowDamage` | `sourceUid, player, row` | предшествует серии `damage` по ряду |
| `draw` | `player, uids` | раздача карт в начале раунда |
| `fizzle` | `sourceUid` | у эффекта нет допустимой цели |

### 1.1 Уникальный идентификатор

`createCard(def)` присваивает `uid` (монотонный счётчик модуля). События ссылаются на `uid`, не на объект.
Карта-копия получает новый `uid` и флаг `isCopy: true`.

## 2. Примитивы — `src/engine/actions.js`

Все эффекты карт собираются из этих функций. Только они пишут события урона, лечения, баффов, щитов и смерти.

| Функция | Правило |
|---|---|
| `dealDamage(match, source, target, n)` | Герой → игнор. Щит → снять щит, событие `shieldBreak`, урон 0. Иначе броня (`armorLeft`) поглощает до `n`, остаток снимает силу. Сила ≤ 0 → `destroy`. |
| `heal(match, source, target, n)` | `power = min(def.power, power + n)` |
| `boost(match, source, target, n)` | `power += n` |
| `giveShield(match, source, target)` | `shielded = true` |
| `copyToHand(match, source, target, playerIdx)` | `createCard(target.def)` с `isCopy: true` → в руку `playerIdx` |
| `destroy(match, card)` | убрать с поля; `doomed` → никуда, иначе → кладбище владельца |

Все существующие эффекты в `effects.js` и `GwentMatch.applyEffect` переводятся на эти примитивы.
Правило `Math.max(1, …)` удаляется везде, кроме погоды (погода влияет только на подсчёт `totalPower`, карты не убивает).
Тики Яда и Кровотечения в `startTurn` идут через `dealDamage` с `source = null` и могут убить карту.

## 3. Таргетинг — `src/engine/targeting.js`

`TARGET_KIND`: эффект → `'enemyUnit' | 'allyUnit' | 'enemyRow' | 'none'`.

`getValidTargets(match, playerIdx, card, effectSlot)` → массив карт (или названий рядов для `enemyRow`).
`effectSlot` равен `'deploy'` или `'order'`.

Правила фильтрации:
- `enemyUnit` / `allyUnit` исключают героев и саму разыгрываемую карту.
- Дополнительные фильтры задаются в определении эффекта (например, Соблазнитель: `power <= 4`).

API:
- `playCard(match, cardIndex, row, { target } = {})`
- `useOrder(match, playerIdx, row, cardIdx, { target } = {})`

Если эффекту нужна цель, а `getValidTargets` пуст, то событие `fizzle`, карта остаётся на поле.
Если цель нужна и допустимые цели есть, а `target` не передан или недопустим, то `Error` (защита от багов UI).

## 4. Раздача по раундам — `src/engine/cardPool.js`

- Раунд 1: рука = 10 случайных карт из колоды игрока (колода перетасовывается через `rng`).
- Перед раундами 2 и 3 (в `startNextRound`, после очистки поля) каждый игрок получает 5 карт из пула своей фракции.
- **Потолок руки: 10.** Выдаётся `min(5, 10 − hand.length)` карт.
- Событие `draw` на каждого игрока.

`buildFactionPool(faction)` = все определения фракции из `starterDecks` + `shopCards`, без тега `leader`.

`dealRandom(pool, count, rng)`:
- Веса: common 50 / rare 30 / epic 15 / legendary 5.
- Максимум 1 legendary на раздачу. Повторная легендарка перебрасывается.
- Дубликаты определений разрешены.

`createMatch(deckA, deckB, { handSize = 10, rng = Math.random } = {})`: сигнатура меняется, все вызовы обновляются.
Фракция игрока берётся из `deck[0].def.faction`.

## 6. Анимации — BattleScene

**Принцип:** анимации проигрываются поверх текущей (старой) отрисовки. `render()` вызывается один раз после завершения очереди.

### 6.1 Файлы

- `src/ui/AnimationQueue.js`: `async play(events)` проигрывает события последовательно. Пока очередь работает, `scene.busy = true`, и все обработчики ввода выходят сразу. Клик во время проигрывания ставит множитель скорости ×3 до конца очереди.
- `src/ui/effectAnimations.js`: словарь `type → (scene, event, speed) => Promise`.
- `CardView.setPower(n)` обновляет цифру силы без перерисовки.
- `scene.viewsByUid: Map<uid, CardView>` заполняется в `render()`.
- Текстура частиц `spark` генерируется через `graphics.generateTexture` при загрузке сцены.

### 6.2 Каталог

| Событие | Анимация | мс |
|---|---|---|
| `play` | карта летит из руки в ряд | 280 |
| `damage` | снаряд от источника к цели → тряска + красная вспышка → `-N`, `setPower` | 400 |
| `shieldBreak` | синий пузырь лопается осколками, «Щит!» | 300 |
| `heal` | зелёные искры вверх, `+N` | 350 |
| `boost` | золотая пульсация, `+N` | 300 |
| `shield` | синий пузырь надувается вокруг карты | 300 |
| `destroy` | карта краснеет, сжимается, рассыпается частицами | 400 |
| `copyToHand` | полупрозрачный двойник летит в руку | 400 |
| `poison` / `bleed` | капля ☠ / 🩸 падает на карту | 250 |
| `rowDamage` | огненная волна по ряду слева направо | 350 |
| `draw` | баннер «Раунд N» → рубашки веером в руку, шаг 120 мс | ~1400 |
| `fizzle` | серый дымок, «Нет цели» | 250 |

`damage` без источника (тик статуса) не рисует снаряд.
Если CardView с нужным `uid` не найден, анимация пропускается и сразу возвращает resolved `Promise`.
Звуки `SoundEngine` вызываются по типу события.

### 6.3 Выбор цели

1. Клик по карте в руке → клик по ряду.
2. Если эффекту нужна цель и цели есть: карта-призрак в ряду, допустимые цели подсвечены оранжевым, остальные затемнены, подсказка «Выберите цель».
3. Клик по цели → `playCard(..., { target })` → `drainEvents` → очередь → `render()`.
4. ПКМ / Esc → отмена, карта остаётся в руке.

Тот же поток используется для Order (существующий `pendingOrder`).

### 6.4 Удаляется

`snapshotPowers`, `computeDiffs`, `flushFloats`, `awaitingHeal`, `healUnit` (заменён эффектом Медика).

### 6.5 Ход ИИ

Пауза 400 мс → ход ИИ → его события через ту же очередь → `render()`.

## 7. ИИ

### 7.1 `src/engine/ai/chooseTarget.js`

`chooseTarget(match, playerIdx, card, effectSlot)` → цель из `getValidTargets` или `null`.

| Эффект | Выбор |
|---|---|
| урон N | враг без щита с `power ≤ N` и максимальной силой (добивание); иначе сильнейший без щита; иначе любой сильнейший |
| лечение | союзник с максимальной потерей `def.power − power` |
| бафф | сильнейший союзник |
| щит | сильнейший союзник без щита |
| дубль | сильнейший союзник |
| яд / кровотечение | сильнейший враг без этого статуса |
| урон ряду | ряд с максимальной суммарной силой врагов-не-героев |
| забрать врага | сильнейший допустимый |

### 7.2 `chooseMove`

- Оценка карты = `power + effectValue`, где `effectValue` — сила карты, которую эффект убьёт на выбранной цели, иначе параметр эффекта (N урона/лечения/баффа), для щита и дубля — 2.
- Если соперник спасовал и ИИ ведёт по очкам → `pass`.
- Возвращает `{ type: 'play', cardIndex, row, target }`.
