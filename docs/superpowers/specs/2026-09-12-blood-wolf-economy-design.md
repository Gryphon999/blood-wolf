# Blood Wolf — Экономика и профиль: дизайн-документ

**Дата:** 2026-09-12
**Слой:** пятый (после engine, effects, battle-screen, menu).

## Цель

Профиль игрока с золотом, коллекцией карт и собранной колодой; экономика (награда за победу, улучшение карт за золото); экран «Колода» для сборки колоды и улучшений. Бой использует колоду из профиля и начисляет золото за победу. Прогресс сохраняется между сессиями.

## Принцип

Логика профиля/экономики — **чистый модуль без Phaser** (как движок Гвинта), покрывается юнит-тестами. Персистентность за адаптером (`localStorage` сейчас, Yandex SDK позже — меняется одно место). Сцена «Колода» только рисует профиль и вызывает чистые функции.

## Объём этого слоя

- **Профиль:** `{ gold, collection: {id:{count,level}}, deck: [id...], faction }`. Начальный профиль = стартовая коллекция (текущие карты игрока) + дефолтная колода.
- **Экономика:** +50 золота за победу в бою; улучшение своей карты (уровень 1→3, +1 силы за уровень, цена: ур.2 = 150, ур.3 = 400).
- **Экран «Колода»:** просмотр коллекции, включение/удаление карт в колоду (валидна при ≥10 картах), улучшение карт за золото, отображение баланса золота, кнопка «В меню».
- **Персистентность:** загрузка профиля при старте, сохранение при каждом изменении.
- **Связка:** бой берёт колоду из профиля (с учётом улучшений — сила = база + (уровень−1)); за победу (winner===0) начисляет золото и сохраняет; результат показывает награду.

## Осознанно отложено (следующие слои)

- **Магазин (покупка новых карт)** — нужен каталог покупаемых карт; отдельный слой.
- **Рейтинг/«Сила»/лидерборд** — нужен Yandex SDK.
- Крафт, редкости-паки, ежедневные награды.

## Архитектура (новые файлы)

- `src/data/cardCatalog.js` — карта `id → определение карты` (собрана из существующих карт игрока и ИИ) + `getCard(id)`; бросает при неизвестном id. Чистый.
- `src/economy/profile.js` — чистая логика:
  - `createProfile()` → начальный профиль (стартовая коллекция + дефолтная колода из каталога).
  - `addGold(profile, amount)` → мутирует `gold`.
  - `upgradeCost(level)` → стоимость перехода на следующий уровень (`2→150`, `3→400`); бросает, если карта уже максимального уровня (3).
  - `canUpgrade(profile, id)` / `upgradeCard(profile, id)` → улучшать можно ТОЛЬКО карты-юниты (`type==='unit'`; у знаков сила 0, герои фиксированы). Проверка типа+золота+уровня (<3), затем списание золота и +1 уровень (макс 3). `upgradeCard` бросает, если улучшить нельзя.
  - `toggleDeckCard(profile, id)` → добавить/убрать карту из колоды (только если есть в коллекции).
  - `isDeckValid(profile)` → `deck.length >= 10`.
  - `buildDeckCards(profile)` → массив определений карт для колоды, с силой = база + (уровень−1) для не-героев (герои не улучшаются в этом слое — база).
- `src/economy/profileStore.js` — `saveProfile(profile, storage?)` / `loadProfile(storage?)`; `storage` по умолчанию `localStorage`, инъекция фейка в тестах; ключ `blood-wolf-profile`; JSON-сериализация; при отсутствии/битых данных → `null` (вызвавший создаёт новый профиль).
- `src/scenes/DeckScene.js` — Phaser: список коллекции (карта-заглушка + уровень + кнопка «Улучшить (цена)»), пометка «в колоде», баланс золота, «В меню». Меняет профиль → сохраняет → перерисовывает.
- Правки:
  - `src/scenes/MenuScene.js` — «Колода» активна → `DeckScene`.
  - `src/scenes/BattleScene.js` — колода игрока = `buildDeckCards(profile)`; при `winner===0` — `addGold(+50)` + `saveProfile`, показать «+50 золота» на экране результата.
  - `src/main.js` — зарегистрировать `DeckScene`; профиль загружается/создаётся в общей точке (напр. `src/economy/session.js` — синглтон `getProfile()` — грузит из store или создаёт).

Зависимости: сцены/economy → data/engine; движок Гвинта и `engine/**` остаются чистыми и не меняются (кроме того, что бой получает колоду извне — он уже принимает колоды параметром).

## Тестирование

- Юнит-тесты (Vitest): `cardCatalog.js` (getCard, неизвестный id), `profile.js` (createProfile, addGold, upgradeCost/upgradeCard границы и списание, toggleDeckCard, isDeckValid, buildDeckCards с улучшениями и иммунитетом героя), `profileStore.js` (save→load кругорейс с фейковым storage, битые данные → null).
- Браузер (claude-in-chrome): меню→Колода, улучшение карты (золото падает, сила растёт), сборка колоды, бой берёт мою колоду, победа даёт золото и сохраняется после перезагрузки.
- Существующие 56 тестов остаются зелёными.
