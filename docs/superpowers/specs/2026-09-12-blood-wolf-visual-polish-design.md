# Blood Wolf — Полировка визуала: дизайн + план

**Дата:** 2026-09-12
**Слой:** восьмой. Процедурная полировка (без внешних ассетов).

## Цель

Атмосферное оформление кодом Phaser: фон-градиент с виньеткой на всех сценах, рамки карт по редкости + бейдж силы, лёгкие оттенки рядов на поле боя. Реальные иллюстрации карт (картинки) — отдельно (нужны файлы).

## Задачи

1. **`src/ui/rarity.js` (чистый) + тест** — `rarityColor(rarity)` → цвет: common 0x8a8a8a, rare 0x4a80c0, epic 0x9a4ac0, legendary 0xffd479, иначе 0x8a6d3b. Юнит-тест.
2. **`src/ui/background.js`** — `drawBackground(scene)`: вертикальный градиент (тёмно-коричневый→почти чёрный) + полоса «тумана» по центру + затемнение сверху/снизу (виньетка). Возвращает Graphics.
3. **`CardView` полировка** — рамка цвета `rarityColor(def.rarity)` (выбранная карта — золотая толще); бейдж силы (кружок с числом) для юнитов/героев; «знак» для спец-карт. Импортирует `rarityColor`.
4. **Сцены** — вызвать `drawBackground(this)` в НАЧАЛЕ `create()` (до создания `root`/контента, чтобы фон был снизу) в `MenuScene`, `BattleScene`, `DeckScene`, `ShopScene`, `StoryScene`.
5. **Поле боя** — `BattleScene.renderRow`: лёгкий оттенок ряда по типу (melee/ranged/siege).

## Тестирование

- Юнит-тест `rarity.js` (цвета по редкости + дефолт).
- Визуально в браузере: минимум скриншотов (меню + бой) — бережём лимит.
- Существующие 83 теста зелёные.

## Порядок (инлайн)

Task 1: rarity.js + тест. Task 2: background.js. Task 3: CardView (рамка+бейдж). Task 4: drawBackground во все 5 сцен + оттенки рядов. Затем build + test + 1-2 скриншота + мёрж.

## Вне рамок

Реальные иллюстрации карт (файлы), анимации, частицы, звук.
