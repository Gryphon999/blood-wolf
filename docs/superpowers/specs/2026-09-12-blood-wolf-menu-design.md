# Blood Wolf — Меню и навигация: дизайн-документ

**Дата:** 2026-09-12
**Слой:** четвёртый (после engine-core, effects, battle-screen).

## Цель

Главное меню как стартовый экран и навигация Меню ↔ Бой. Замыкает игру в связный цикл: игрок стартует в меню, входит в бой, возвращается в меню.

## Рамки

- `MenuScene` — стартовая сцена (Phaser грузит её первой).
- Заголовок «Blood Wolf» + 4 кнопки: **Бой**, **Колода**, **Магазин**, **Рейтинг**.
- **Бой** активна → `this.scene.start('BattleScene')` (сцена уже готова).
- **Колода / Магазин / Рейтинг** — неактивны, с меткой «скоро» (экранов ещё нет; YAGNI). Активируются в будущих слоях.
- `BattleScene` получает кнопку **«В меню»** (в углу во время боя и на экране результата) → `this.scene.start('MenuScene')`.
- Каждый вход в бой — свежий матч (`create()` в BattleScene уже создаёт новый `createMatch`, повторный `scene.start` вызывает `create` заново).

## Архитектура

- `src/ui/Button.js` — переиспользуемый компонент кнопки: `createButton(scene, x, y, label, { enabled = true, onClick })` → Phaser-контейнер (прямоугольник + текст), кликабелен только при `enabled`; неактивная — приглушённая. Без игровой логики.
- `src/ui/menuLayout.js` — **чистый** модуль: `menuButtonY(index)` и константы (позиции кнопок по вертикали, центр по X). Юнит-тестируется.
- `src/scenes/MenuScene.js` — рисует заголовок и кнопки через `Button` + `menuLayout`; «Бой» стартует бой, прочие неактивны.
- `src/main.js` — регистрирует сцены `[MenuScene, BattleScene]` (меню первым).
- `src/scenes/BattleScene.js` — добавить кнопку «В меню» (в углу + на оверлее результата), переход в `MenuScene`.

Зависимости: сцены/ui → движок; движок чист (без Phaser/DOM), не меняется.

## Тестирование

- `src/ui/menuLayout.js` — юнит-тесты (Vitest): координаты кнопок детерминированы, по порядку, в пределах экрана.
- `Button.js`, `MenuScene`, кнопка «В меню» — проверка сборкой (`npm run build`) + вживую в браузере (claude-in-chrome): меню рисуется, «Бой» открывает бой, «В меню» возвращает, неактивные кнопки не реагируют.
- Существующие 51 тест остаются зелёными.
