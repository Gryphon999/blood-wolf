## 1. Ключевые механики

### 1.1 Abilities (способности карт)

Каждая карта может иметь одну из двух активных механик:

**Deploy** — срабатывает один раз при выходе на поле.  
Примеры: `deploy: +1 за Рыцаря`, `deploy: poison enemy`, `deploy: resurrect`.

**Order** — активная способность, можно использовать раз в ход (если не Zeal).  
В движке: `orderUsed: boolean`, сбрасывается в `false` в начале хода игрока.  
Иконка: зелёная точка = готова, серая = использована.

**Zeal** — Order можно применить в тот же ход, когда карта вышла на поле.

**Charge N** — Order можно применить N раз за игру (не сбрасывается каждый ход).  
Используется для Лидеров.

### 1.2 Статус-эффекты (10 штук)

| Эффект | Значок | Описание |
|--------|--------|----------|
| Poison (Яд) | ☠ | −1 сила в начале каждого хода. Снимается Священником. |
| Bleeding (Кровотечение) | 🩸 | −1 сила в начале каждого хода. Несколько экземпляров суммируются. |
| Armor (Броня) | 🛡N | Первые N единиц урона поглощаются. Не суммируется. |
| Shield | 🔮 | Следующий эффект (урон/дебафф) игнорируется. Одноразовый. |
| Resilience | 🌿 | Карта не сбрасывается между раундами — остаётся на поле. |
| Doomed | 💀 | Когда карта уходит с поля — идёт в сброс, не на кладбище. |
| Boost | ↑N | Постоянный бонус к силе при выполнении условия. |
| Lock (Блок) | 🔒 | Способности заблокированы. Order не работает. Снимается картой. |
| Immune | ⚡ | Нельзя нанести Яд, Кровотечение, Блок, погоду. |
| Burn (Горение) | 🔥 | Минус 2 в начале хода. Только от Демон-карт. |

### 1.3 Система Provisions (Провижны)

Каждая карта имеет стоимость в Provisions.  
Бюджет колоды: **160 Provision points** (балансируется в финальном плане).  
Золотые карты дороже (10–12), бронзовые дешевле (3–8), Лидеры — бесплатно.

Смысл: нельзя взять все мощные карты в одну колоду — нужен компромисс.

### 1.4 Победа в раунде

Раунд выигрывает тот, у кого больше суммарная сила на поле.  
При пасе (pass) игрок не выкидывает больше карт в этом раунде.  
При ничье — очко обоим.  
Лучший из 3 раундов выигрывает матч.

### 1.5 Категории (теги)

Карты имеют один или несколько тегов. Теги активируют синергии:

**Люди:** Рыцарь, Лучник, Медик, Осада, Машина, Зилот  
**Монстры:** Нежить, Зверь, Демон, Великан

## 4. Баланс колод

### Стартовая колода людей (12 карт, ~60 Provisions)

merc_a, merc_b, merc_c, knight, archer_a, archer_b, catapult, champion, warhorn, frost, clear_sky, medic

### Стартовая колода монстров / AI (10 карт, ~42 Provisions)

ghoul_a, ghoul_b, ghoul_c, harpy_a, harpy_b, troll_a, troll_b, beast, blight, fog

### Балансные принципы

- Золотые карты: 10–12 Prov, сила 5–9. Не более 4 золотых в колоде.
- Синергетические карты (Волки, Рыцари) дешевле по отдельности, дорого в сумме.
- Doomed-карты получают скидку −2 Prov (рискованная механика).
- Immune/Resilience-карты дороже на +2–3 Prov.
- Лидеры бесплатны, ограничение: 1 на колоду.

## 5. Визуальный дизайн карты (B-style: Art First)

### Структура фрейма

```
┌─────────────────┐
│ [STATUS] [PROV] │  ← значки слева, провижны справа (overlay поверх арта)
│                 │
│   A R T         │  ← арт ~60% высоты карты
│                 │
│   ИМЯ           │  ← имя поверх арта (gradient overlay)
├─────────────────┤
│ [TAG] [TAG]     │  ← категории-пилюли
├─────────────────┤
│ Deploy: текст   │  ← ability text
├─────────────────┤
│ PWR       [ARM] │  ← сила (большая) + броня/Order-точка
└─────────────────┘
```

### Цветовые схемы

| Тип | Рамка | Арт-фон | Имя | Теги |
|-----|-------|---------|-----|------|
| Бронза (Люди) | `#4a3060` | `#1a0f2a → #2d1a40` | `#e0d0ff` | фиолетовые |
| Золото (Люди) | `#ffd700` + glow | `#1a1000 → #3d2a00` | `#ffd479` | золотые |
| Бронза (Монстры) | `#3a6040` | `#0a1a0a → #1a3015` | `#a0ffa0` | зелёные |
| Золото (Монстры) | `#60ff60` + glow | `#120808 → #251210` | `#a0ffa0` | зелёные |
| Special | `#707070` | `#0e0e0e → #1a1a1a` | `#d0d0d0` | серые |
| Leader | `#ff8040` + glow | `#180808 → #301010` | `#ffb070` | оранжевые |

### UI-иконки

- **Order готов:** зелёная точка 6×6 с glow (#50e080)
- **Order использован:** серая точка (opacity 0.3)
- **Charge N:** N точек (оранжевые для Лидеров)
- **Armor:** `🛡N` badge в нижнем правом углу
- **Provisions:** синий badge `#9ab8ff` в верхнем правом углу арта

### Статус-иконки на карте (верхний левый угол арта)

- 🌿 Resilience
- 💀 Doomed  
- 🔮 Shield (активен)
- 🔒 Lock (заблокирован)

## 6. Расширенные механики движка

### Deploy-триггеры

```js
// В GwentMatch.playCard():
if (card.effect === 'deploy_knight_bonus') {
  const knightCount = board[playerIdx][card.row].filter(c => c.tags.includes('knight')).length;
  card.power += knightCount;
}
```

### Order-механика

```js
// Новые поля в объекте карты:
{
  hasOrder: true,
  orderUsed: false,
  chargeMax: 2,       // для Charge 2
  chargesLeft: 2,
  zeal: false,
}
// В начале хода активного игрока: все orderUsed → false (кроме chargesLeft = 0)
```

### Status-эффекты в начале хода

```js
// Bleeding/Poison tick:
board[playerIdx].forEach(row => row.forEach(card => {
  if (card.bleedStacks > 0) card.power = Math.max(1, card.power - card.bleedStacks);
  if (card.poisoned) card.power = Math.max(1, card.power - 1);
}));
```
